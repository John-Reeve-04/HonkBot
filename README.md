# HonkBot

## Description
A public facing repository for my VUW ENGR489 capstone project.

The Honk Bot system is one of education through engineering. It aims to educate the public about the ship horns they hear in Wellington Harbour in a fun way.

### Features
- Main project (In progress):
  - Detects ship horn noises from audio input
  - Creates and publishes social media posts about the noises that are detected.
- Demo: See the file header comment.
